Getting started

Installation & step-by-step setup

The course website is static HTML. You do not need Node.js or a web server to read it. Python is only necessary for hands-on code.

Step 1 — Unzip and open

Extract Agentic_AI_End_to_End_HTML_Tutorial.zip.
Open agentic_ai_academy/index.html in Chrome, Safari, Edge or Firefox.
Choose Lesson 01 in the sidebar. Use the search field to filter lessons. Each code block has a Copy button.
Open a terminal in the extracted agentic_ai_academy folder.

Step 2 — Python environment

python3 --version  # Python 3.11+ recommended
python3 -m venv .venv
source .venv/bin/activate          # macOS/Linux
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python examples/01_agent_loop.py
python examples/02_tool_registry.py
python -m unittest discover -s examples -p 'test_*.py'

Step 3 — Optional framework packages

Install only the packages needed for the examples you want to run. Dependencies are not required to browse HTML.

python -m pip install -r requirements-optional.txt
# To run hosted model examples, configure OPENAI_API_KEY in your shell:
export OPENAI_API_KEY="your-key-here"
python examples/06_openai_agents.py
python examples/07_langchain_agent.py
python examples/08_langgraph.py
# MCP server example starts a stdio server; connect it from an MCP client:
python examples/09_mcp_server.py

Step 4 — Study sequence

Read each module, write its algorithm on paper, run the linked example, vary an input, induce a failure deliberately, and implement the assignment. After Modules 1–7, build a toy agent. After Modules 8–16, create a stateful graph with an MCP tool. After Modules 17–30, design a production system with approval gates.

Security: Never paste real API keys into HTML or source control. Hosted agent examples require connectivity and may incur provider charges. Terminal and deployment examples are intentionally simulated or restricted.
