Syntax and architecture cheat sheet

PatternMeaningWhen to use
Tool dispatchValidate call arguments and execute allowlisted functionAll agents with capabilities
ReActThink/act/observe iterativelyDynamic tool selection
StateGraphNodes + edges + typed state updatesExplicit branching and durable workflows
CheckpointSave resumable execution snapshotLong-running tasks or approval pauses
RAGRetrieve evidence before composing an answerGrounded document questions
MCPExpose tools, resources and promptsStandardized external integrations
Human gateBind authorization to a proposed actionWrites, payments, production changes
