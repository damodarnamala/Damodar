Agent memory

Learning outcome: Compare short-term, semantic, episodic and persistent memory

1. What is it?

Short-term context keeps the immediate conversation; durable memory stores selected information for future tasks. Memories can be wrong or stale and require explicit retention and deletion rules.

2. Why does it matter?

Do not store secrets or sensitive details indiscriminately. Enforce user and tenant isolation.

Concrete scenario: Remember only consented user preferences. The figure below names the actual components and shows how information moves among them.

Every branch is controlled by application code. A model can recommend an action, but it does not automatically gain permission to perform that action. Record observations and check the terminal condition after every step.

6. Runnable Python lesson

This module links to 03_memory.py. Some modules reuse an earlier example intentionally: revisit it and identify which concept is newly relevant. The downloadable file is in the examples/ folder.

Run locally: python examples/03_memory.py from the extracted project root. Examples using provider libraries also need the dependencies and credentials explained in Setup.
"""Bounded memory; intentionally no secrets or durable persistence."""
from collections import deque

class ConversationMemory:
    def __init__(self, max_messages: int = 6):
        self.messages = deque(maxlen=max_messages)

    def add(self, role: str, content: str) -> None:
        if role not in ("user", "assistant"):
            raise ValueError("Invalid role")
        self.messages.append({"role": role, "content": content})

    def context(self) -> list[dict[str, str]]:
        return list(self.messages)

if __name__ == "__main__":
    m = ConversationMemory(2)
    m.add("user", "Hello")
    m.add("assistant", "Hi")
    m.add("user", "Again")
    print(m.context())

8. Real-world design exercise

You are building a agent memory capability for an enterprise assistant. It must complete a user task while preserving authorization, explicit failure states, and observable results.

Build task: Implement a bounded conversation buffer. Start with one valid scenario, one invalid input and one failure case. Add an explicit max-step or timeout condition and document whether the workflow has side effects.

9. Common mistakes and troubleshooting

  • Saving sensitive information without consent. Mitigation: make this condition explicit in a test or a runtime policy.
  • Injecting irrelevant memory into every prompt. Mitigation: make this condition explicit in a test or a runtime policy.

10. Practice and knowledge check

In memory lifecycle architecture, what happens between “Memory extraction” and “Context injection”, and what must be checked?

Follow the labeled arrows in the diagram: Memory extraction hands a defined result through the intermediate stages toward Context injection. For this topic, explicitly guard against saving sensitive information without consent.

How do you stop an agent from looping forever?

Use a maximum step count, time limit, cost budget and explicit terminal condition.

How do you prove that the result is correct?

Use independent deterministic validation, trusted source evidence, tests and human approval as appropriate.
