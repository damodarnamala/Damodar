Retrieval and RAG

Learning outcome: Ground answers in retrieved evidence

1. What is it?

RAG retrieves candidate evidence, filters/ranks it, and gives the model relevant passages. Retrieval quality often matters more than prompt cleverness. An agentic RAG workflow may rewrite the query or choose different sources.

2. Why does it matter?

Carry source IDs and quote spans through retrieval so answers can be checked.

"""Deterministic prerequisite scheduler and cycle detection."""
def schedule(tasks: dict[str, list[str]]) -> list[str]:
    result, completed = [], set()
    unknown = {d for deps in tasks.values() for d in deps} - set(tasks)
    if unknown:
        raise ValueError(f"Unknown dependencies: {unknown}")
    while len(completed) < len(tasks):
        ready = sorted(k for k, deps in tasks.items()
                       if k not in completed and set(deps) <= completed)
        if not ready:
            raise ValueError("Dependency cycle")
        result.extend(ready)
        completed.update(ready)
    return result

if __name__ == "__main__":
    tasks = {"requirements": [], "code": ["requirements"],
             "tests": ["code"], "review": ["tests"]}
    print(schedule(tasks))

8. Real-world design exercise

You are building a retrieval and rag capability for an enterprise assistant. It must complete a user task while preserving authorization, explicit failure states, and observable results.

Build task: Implement TF-IDF retrieval without external services. Start with one valid scenario, one invalid input and one failure case. Add an explicit max-step or timeout condition and document whether the workflow has side effects.

9. Common mistakes and troubleshooting

  • Answering without preserving passage IDs. Mitigation: make this condition explicit in a test or a runtime policy.
  • Confusing embedding similarity with factual correctness. Mitigation: make this condition explicit in a test or a runtime policy.

10. Practice and knowledge check

In rag indexing and answering pipelines, what happens between “Chunk + embed” and “Grounded answer”, and what must be checked?

Follow the labeled arrows in the diagram: Chunk + embed hands a defined result through the intermediate stages toward Grounded answer. For this topic, explicitly guard against answering without preserving passage ids.

How do you stop an agent from looping forever?

Use a maximum step count, time limit, cost budget and explicit terminal condition.

How do you prove that the result is correct?

Use independent deterministic validation, trusted source evidence, tests and human approval as appropriate.
