LangChain modern agents

Learning outcome: Create model-assisted agents with modern LangChain APIs

1. What is it?

Modern LangChain exposes create_agent and tools while LangGraph provides lower-level explicit graph orchestration. Older create_react_agent examples may be deprecated.

2. Why does it matter?

4. Topic-specific architecture and execution flow

Every branch is controlled by application code. A model can recommend an action, but it does not automatically gain permission to perform that action. Record observations and check the terminal condition after every step.

5. Step-by-step algorithm

  1. create_agent: Process the create_agent stage, and pass its defined output to the next node.
  2. Chat model: Process the chat model stage, and pass its defined output to the next node.
  3. @tool schema: Process the @tool schema stage, and pass its defined output to the next node.
  4. Authorized tool: Process the authorized tool stage, and pass its defined output to the next node.
  5. Tool message: Process the tool message stage, and pass its defined output to the next node.
  6. Final response: Emit a result only after verifying the stated conditions.

6. Runnable Python lesson

This module links to 07_langchain_agent.py. Some modules reuse an earlier example intentionally: revisit it and identify which concept is newly relevant. The downloadable file is in the examples/ folder.

Run locally: python examples/07_langchain_agent.py from the extracted project root. Examples using provider libraries also need the dependencies and credentials explained in Setup.
"""Requires: pip install langchain langchain-openai and OPENAI_API_KEY."""
from langchain.agents import create_agent
from langchain.tools import tool

@tool
def get_policy(topic: str) -> str:
    """Return the demonstration policy for a topic."""
    return {"refund": "Demo refund window: 14 days."}.get(topic.lower(), "No matching policy")

agent = create_agent(model="openai:gpt-4.1-mini", tools=[get_policy],
                     system_prompt="Answer policy questions; call get_policy when relevant.")

if __name__ == "__main__":
    result = agent.invoke({"messages": [{"role": "user", "content": "Explain refund policy"}]})
    print(result["messages"][-1].content)

8. Real-world design exercise

You are building a langchain modern agents capability for an enterprise assistant. It must complete a user task while preserving authorization, explicit failure states, and observable results.

Build task: Build a LangChain tool agent. Start with one valid scenario, one invalid input and one failure case. Add an explicit max-step or timeout condition and document whether the workflow has side effects.

9. Common mistakes and troubleshooting

  • Copying deprecated agent constructors. Mitigation: make this condition explicit in a test or a runtime policy.
  • Assuming a model can execute tools itself. Mitigation: make this condition explicit in a test or a runtime policy.

10. Practice and knowledge check

In langchain tool-enabled agent flow, what happens between “Chat model” and “Final response”, and what must be checked?

Follow the labeled arrows in the diagram: Chat model hands a defined result through the intermediate stages toward Final response. For this topic, explicitly guard against copying deprecated agent constructors.

How do you stop an agent from looping forever?

Use a maximum step count, time limit, cost budget and explicit terminal condition.

How do you prove that the result is correct?

Use independent deterministic validation, trusted source evidence, tests and human approval as appropriate.
