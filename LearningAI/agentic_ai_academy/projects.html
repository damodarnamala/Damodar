AI Software Factory reference workflow

JIRA TICKET → REQUIREMENTS → ARCHITECTURE → PLAN ↓ ↓ TRACE ID REPO ANALYSIS ↓ SANDBOXED PATCH ↓ TESTS + SECURITY SCAN ↓ HUMAN CODE REVIEW ↓ PULL REQUEST / CI ↓ RELEASE APPROVAL GATE ↓ CONTROLLED DEPLOY ↓ MONITOR / ROLLBACK

Exit criteria

Require reproducible tests, no unauthorized tool calls, a reviewable patch, auditable approvals, monitored deployment, clear ownership and a rollback runbook before calling the capstone production ready.
