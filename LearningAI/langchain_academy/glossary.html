LangChain glossary

Quick definitions of course terminology.

Tokens

Units of text used for context and billing; not necessarily full words.

Context window

Total token capacity shared by instructions, history, retrieved documents and generated output.

Temperature

Sampling control; smaller values generally reduce variation but do not guarantee determinism.

Embeddings

Vectors encoding semantic information for similarity-based retrieval.

Transformers

Neural networks with attention mechanisms that process context relationships.

Hallucinations

Plausible output not grounded in reliable evidence; address with retrieval and validation.

langchain

High-level agent and model integration APIs.

langchain-core

Messages, prompts, runnables, documents and common interfaces.

Provider packages

Install langchain-openai or another supported provider adapter.

invoke

Run a model or runnable synchronously with an input.

Environment

Set OPENAI_API_KEY in your shell, never in source control.

Packages evolve

Compare code against installed package versions and official documentation.

SystemMessage

Instruction governing assistant behavior.

HumanMessage

End-user input.

AIMessage

Model output, potentially including tool calls.

ToolMessage

Response to a prior tool call with a matching tool-call identifier.

stream

Yields output chunks as generated.

batch and ainvoke

Process multiple inputs or use asynchronous execution.

Template variables

Values replaced at runtime; missing values generally raise errors.

Few-shot

Give a small number of representative demonstrations.

Message placeholders

Inject existing messages such as conversation history.

Prompt injection

User or retrieved text that tries to override trusted instructions.

Instruction hierarchy

Keep system instructions separate from user-provided documents.

Output contract

Specify schema, format and refusal handling explicitly.

RunnableSequence

Stages executed in sequence.

RunnableParallel

Independent branches executed and collected into one dictionary.

RunnableLambda

Wrap an ordinary Python function as a runnable.

RunnablePassthrough

Forward input, optionally assigning additional derived fields.

invoke / ainvoke

Synchronous and asynchronous single-item invocation.

batch / stream

Multiple-input processing and incremental output.

Pydantic

Define fields, types and validators in Python.

Provider-native outputs

Model provider enforces schema where supported.

Tool-based parsing

Some providers support structure through tool calling.

Validation error

Reject incompatible values; retry cautiously or ask for correction.

Optional fields

Use explicit optional types and defaults as needed.

Safety

Validate downstream authorization independently of schema validity.

Document

A page_content string plus a metadata dictionary.

Loader

Reads content from PDFs, websites, CSVs or other sources.

Chunk size

Maximum approximate characters in this splitter, not tokens.

Chunk overlap

Repeated text at boundaries to retain surrounding context.

Metadata

Source, page number, title and access-control information.

Preprocessing

Deduplicate, normalize and redact data before indexing.

Cosine similarity

dot(a,b) / (norm(a)*norm(b)); measures angle between nonzero vectors.

Dot product

Often used with normalized embeddings for efficient ranking.

Euclidean distance

Straight-line distance in vector space.

ANN

Approximate nearest neighbor search trades some recall for speed.

FAISS / Chroma

Common local vector-search options with different persistence behavior.

Filtering

Restrict by trusted metadata and tenant before returning documents.

Indexing

Offline ingestion: load, chunk, embed and store.

Retrieval

Online query: rank and select relevant evidence.

Hybrid search

Combine sparse keyword and dense embedding retrieval.

Reranking

Second-stage model improves ordering of retrieved candidates.

Citation fidelity

Store source identifiers and require evidence for each claim.

Evaluation

Measure context relevance, groundedness, recall and answer quality.

Short-term memory

Thread-scoped context maintained across agent turns.

Long-term memory

Explicit user or task facts stored beyond one thread.

Checkpoint

Durable snapshot of graph state enabling recovery.

thread_id

Stable identifier for conversation state; isolate users securely.

Summarization

Compress older messages while retaining important facts.

Production

Use database-backed persistence rather than in-memory storage.

Tool schema

Name, description and validated input arguments.

Tool call

Structured model request to invoke named functionality.

Execution boundary

Your app executes tools; models do not receive blanket authority.

Allowlist

Expose only tools required for the task.

Side effects

Require authorization and confirmation for destructive actions.

Idempotency

Avoid duplicate financial, external or deployment operations on retry.

Agent vs chain

Chain follows a known sequence; agent selects among actions.

ReAct

Reason-act-observe pattern for iterative tool use.

create_agent

Modern LangChain high-level agent construction API.

Tool loop

Call model again after a tool result until final answer.

Guardrails

Limit iterations, budgets, permissions and allowed tools.

Escalation

Hand off ambiguity or high-impact actions to humans.

StateGraph

Declarative graph builder parameterized by shared state.

Node

Function mapping current state to a partial state update.

Edge

Control flow between nodes.

Conditional edge

Select next node based on state and routing function.

Reducer

Function merging concurrent updates to the same state key.

compile

Validate and transform the builder into an executable runnable.

Supervisor

Coordinates specialized workers and completion criteria.

Handoff

Explicit transfer of control and relevant context.

Shared state

Common artifacts and decisions visible to authorized agents.

Parallel workers

Independent agents can run concurrently then merge outputs.

Conflict resolution

Use review policies and deterministic acceptance tests.

Complexity cost

More agents increase latency, coordination cost and failure modes.

Host

App that orchestrates model and MCP client connections.

Client

Protocol peer connecting to a specific MCP server.

Server

Advertises named tools, resources and/or prompt templates.

Resources

Structured context made available by a server.

Transport

Common options include stdio and streamable HTTP.

Least privilege

Limit server access, enforce authentication and verify outputs.

Planner

Breaks objective into manageable tasks and dependencies.

Reflection

Model critiques its own output; use independent tests too.

Routing

Choose workflow branch from explicit criteria.

Human-in-the-loop

Pause for approval before costly or irreversible actions.

Budget

Cap steps, tool calls, tokens, runtime and retry attempts.

Recovery

Save checkpoints and resume without repeating side effects.

Unit tests

Mock external dependencies; assert deterministic behavior.

Integration tests

Exercise real model/tool boundaries in a test environment.

LangSmith

Trace calls, inspect model inputs, and run evaluations.

RAG metrics

Measure retrieval precision/recall and answer groundedness.

Agent metrics

Track success, tool misuse, latency, cost and termination.

Regression suite

Replay known cases after prompt, model or package changes.

Timeouts

Define hard deadlines for provider and tool calls.

Rate limiting

Enforce per-user or tenant quotas and abuse prevention.

Retries

Exponential backoff with jitter; avoid repeating side effects.

Secrets

Environment or secret manager; rotate and never log API keys.

Telemetry

Trace ID, latency, cost, errors and redacted payloads.

Deployments

Containerize, use health checks and staged rollout gates.

Chatbot

Model invocation with messages and streaming.

Extractor

Pydantic structured outputs with validation.

Document Q&A

Chunking, embeddings, retrieval and citations.

Research agent

Allowlisted tools, timeouts and source validation.

Workflow

Explicit graph state and recovery checkpoints.

Software factory

Issue → plan → branch → patch → tests → PR → approval; no uncontrolled production access.
