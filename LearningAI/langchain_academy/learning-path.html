Your learning path

A suggested order to build progressively from model basics to reliable agentic applications.

Foundations 1–4
→
LCEL & data 5–8

Milestone-based learning

Stage 1: Modules 1–5: explain messages, prompts and composition without looking at notes.

Stage 2: Modules 6–10: create typed extraction and a source-grounded RAG system.

Stage 3: Modules 11–16: understand tool permissions, agent loops, graph state and MCP.

Stage 4: Modules 17–19: add testing, observability, approvals and deployment hygiene.

Review checklist

For every module, write down: input type, output type, core algorithm, one expected failure, one unit test and one security consideration. Complete one project per stage instead of trying all ten simultaneously.
