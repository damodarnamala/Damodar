Start here

Prerequisites: Python 3.10+ recommended, basic familiarity with Python functions and dictionaries, and a terminal. Most code examples need an internet connection and a provider API key to execute, though the tutorial pages, navigation, quizzes and progress tracking work offline.

Python · example
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install -U langchain langchain-core langchain-openai \
  langgraph langchain-text-splitters pydantic
export OPENAI_API_KEY="your-key"  # Windows PowerShell: $env:OPENAI_API_KEY="your-key"

Use one provider integration at a time and check model identifiers against your account. Never commit credentials. Module-specific packages are identified in their examples.

How this site works

All internal navigation uses relative HTML links, so opening index.html directly works even under file://. No Node installation, backend or CDN is required. Search filters the sidebar; copy buttons work with clipboard fallback; revealed quiz answers and local progress are browser-side features.

Scope: This is a broad concept-first course with runnable teaching snippets and project implementation plans. It is not a substitute for provider credentials, deployment infrastructure or complete ten-project source repositories.
